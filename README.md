# UNO 手表版

UNO 是一款运行在 vivo BlueOS 智能手表上的卡牌游戏，适配圆屏和方屏设备。游戏围绕颜色、数字和功能牌展开，适合在手表上进行轻松、快速的对局。

## 下载

下载 [UNO 手表版 RPK 安装包](UNO-watch-v1.0.0.rpk)。仓库提供编译后的应用包，不包含游戏源代码。

## 游戏简介

你将与玩家1、玩家2进行 UNO 对局。大家轮流出牌，设法尽快打完手牌；最先出完手牌的人获胜。出牌时需要观察弃牌堆顶牌的颜色和数字或功能，并合理使用万能牌、抽牌和过牌操作。

## 玩法规则

1. **出牌匹配**：打出的牌需要与弃牌堆顶牌颜色相同，或数字、功能相同。
2. **万能牌**：可以在任意时机打出；打出后选择接下来使用的颜色。
3. **万能牌 +4**：只有手中没有当前颜色的牌时才能打出；打出后选择颜色，下家抽4张牌并跳过本回合。
4. **功能牌**：
   - **跳过**：跳过下一位玩家的回合。
   - **反转**：改变出牌方向。
   - **+2**：下一位玩家抽2张牌并被跳过。
5. **抽牌与过牌**：没有可出的牌时点击“抽牌”抽1张。抽到可出的牌后可以立即打出；如果仍不能出牌，再点击一次“抽牌”过牌。
6. **喊 UNO**：手牌剩下最后1张时，及时点击“UNO!”。需要在3秒内喊出，否则系统会强制罚抽2张牌。

## 手表操作

- 点击手牌选中要出的牌，再点击“出牌”。
- 点击“抽牌”抽牌；抽到可出的牌时可继续选择并出牌。
- 需要改变牌的颜色时，在颜色选择界面点击红、绿、蓝或黄。
- 只剩1张手牌时点击“UNO!”。
